# ChromeDecrypt

Chrome browser credential and cookie decryption tool with App-Bound Encryption support for authorized penetration testing.

## Features

- Chrome App-Bound Encryption (ABE) bypass
- AES-GCM cookie/credential decryption
- Indirect syscall stubs for evasion
- Reflective DLL injection payload

## Build

Requires Visual Studio with C/C++ tools and Windows SDK.

```
make
```
